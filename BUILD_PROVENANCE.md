# Build provenance and disclosure

Proofline Strands was created for the 2026 Agents for Humans hackathon by Akinola Olayinka as a solo entrant.

## Reused entrant-authored foundation

The deterministic safety kernel, initial Slack/Stripe/Salesforce adapters, proof console, and associated reliability tests were first implemented by the entrant for the Multi-App AI Agent Hackathon on September 13, 2026. That work was created during the Agents for Humans submission period and is available in the original public repository:

- <https://github.com/napsterly/proofline>

## New Agents for Humans work

The following work was created specifically for this project on September 14, 2026:

- AWS Strands Agents SDK integration
- Structured-output Strands intent agent
- Strands operator agent with five custom guarded tools
- Sequential tool-execution policy and evidence-grounded system prompt
- AgentCore-compatible `/ping` and `/invocations` runtime endpoints
- Reproducible Node 22 AgentCore bundle and deployment runbook
- Strands boundary tests
- Pro Agents positioning, architecture, documentation, and a new demo narrative

Git history in this repository records the Strands-specific implementation. No dates, authorship, or prior submission history are intentionally concealed.
